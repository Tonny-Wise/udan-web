EXPORT FORMATS
═══════════════════════════════════════════════════════════════════════════════

CSV Format:
  • File: udan-registrations-YYYY-MM-DD.csv
  • Best for: Quick imports, other systems
  • Size: ~5-10KB

Excel Format:
  • File: udan-registrations-YYYY-MM-DD.xlsx
  • Best for: Analysis, formatting, sharing
  • Size: ~50-100KB
  • Features: Styled headers, auto-fitted columns

PDF Format:
  • File: udan-registrations-YYYY-MM-DD.pdf
  • Best for: Archiving, official reports, printing
  • Size: ~100-200KB
  • Features: Professional layout, timestamp

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

🔴 "Invalid password" error
  → Check .env.local has ADMIN_PASSWORD set
  → Restart dev server after changing password

🔴 Export button doesn't work
  → Check browser console (F12) for errors
  → Verify Supabase connection
  → Try refreshing the page

🔴 No registrations showing
  → Verify data exists in Supabase members table
  → Check Supabase credentials in .env.local
  → Try refreshing page
