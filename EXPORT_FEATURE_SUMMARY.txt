HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

1. User clicks any export button (CSV, Excel, or PDF)
2. Browser sends request to: /api/export-registrations?format=[format]
3. Backend API:
   ✓ Fetches all registrations from Supabase
   ✓ Formats data based on selected format
   ✓ Generates file in memory
   ✓ Returns file as downloadable attachment
4. Browser automatically downloads file with timestamp
